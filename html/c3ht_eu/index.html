Log in

You are using the password printed on the card. Anyone who has seen the card can log in. You can set your own password below (recommended: Generate).

Status

Wi-Fi switches off automatically (- s left). It starts again only when you press BOOT or choose "VRx Wi-Fi" and then press BOOT.

Head tracking

pitch - · roll - · yaw -

Board orientation

Rotate from flat, level and pointing away from you: first pitch (back is positive), then roll (right is positive), then yaw (left is positive).

Firmware update

Only firmware signed for this device type is accepted (-). Unsigned or modified files are rejected. You can always install any firmware, including your own build, over USB (see the manual).

Device password

One password is used for the Wi-Fi network and for this page. A new password takes effect the next time Wi-Fi starts; your phone will ask for it then. Holding BOOT for 10 seconds brings back the card password.

Security log

Factory reset

Erases your password, binding, IMU calibration and the log. The card password works again afterwards.
